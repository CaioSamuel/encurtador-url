# encurtador-url
Encurtador de URLs

Encurta URLs longas gerando um código curto de 6 caracteres que redireciona para o endereço original.

Tecnologias utilizadas: Python e Django

Para rodar (no terminal):

# crie uma venv
```bash
python -m venv venv
```

# ative a venv
```bash
venv/Scripts/activate
```

# baixe o django
```bash
pip install django
```

# aplique as migrations
```bash
python manage.py makemigrations
```

```bash
python manage.py migrate
```

# rode o projeto
```bash
python manage.py runserver
```
